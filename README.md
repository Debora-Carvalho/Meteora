# Meteora 🛍️✨

## 📄 Resumo
Meteora é um projeto desenvolvido no curso **Bootstrap 5: desenvolvimento de websites responsivos e atraentes**, da Alura. O projeto consiste em uma landing page para uma loja virtual, aplicando os conceitos aprendidos para criar um design moderno, responsivo e visualmente atraente utilizando Bootstrap 5.

![Imagem do Projeto](./assets/print-site.png)  

## ⚙️ Tecnologias Utilizadas
- HTML5
- CSS3
- Bootstrap 5
